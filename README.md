# Librería Online · Libros, Manga y Cómics

> 🚧 **En construcción.** Proyecto de portafolio: tienda online de demostración hecha con HTML, CSS y JavaScript Vanilla, sin frameworks ni dependencias.

## Avance

- [x] Estructura base, design tokens y modo claro/oscuro persistente
- [x] Header responsivo con menú móvil, hero y footer
- [x] Catálogo dinámico desde JSON, categorías, skeletons y estados de error
- [ ] Filtros combinables y búsqueda en tiempo real (sincronizados con la URL)
- [ ] Carrito persistente con `localStorage`
- [ ] Pedido simulado vía WhatsApp
- [ ] Modal de detalle, carrusel de novedades y pulido de accesibilidad
- [ ] Documentación final y despliegue

## Ejecutar localmente

El catálogo se carga con `fetch`, así que se necesita un servidor HTTP (abrir `index.html` con doble clic no funciona):

```bash
npx serve .
# o la extensión Live Server de VS Code
```
